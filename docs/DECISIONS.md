# 维护决策记录

## ADR-001：采用稳定 OrangeChat 基线 + selective backport 的维护模式

- 状态：已采纳
- 日期：2026-08-11

### 背景

OrangeChat 保留了自身独有的功能和使用方式。频繁整仓同步快速变化的上游会扩大回归风险、增加冲突，并提高长期维护复杂度。

### 决策

- 不定期整仓 merge 最新 RikkaHub。
- 只 backport 已明确需要、能够独立审查并经过验证的修复和功能。
- 优先降低长期维护复杂度，而不是追求与上游提交数量同步。
- 保持 OrangeChat 独有功能稳定，避免无关上游改动造成行为变化。

### 影响

每项上游移植都需要说明动机、影响范围和验证结果。重要兼容性与安全修复应优先评估，但仍须通过独立分支、代码审查和 Debug CI 后才能进入 `master`。
